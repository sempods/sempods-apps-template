# Spike #120: UI primitives and role tokens

Evidence for [the write-up](../../docs/spikes/120-ui-primitives.md). Nothing
here ships: this folder is its own pnpm workspace, outside the template's
`packages/*`, and the template's `check` does not build it.

## Layout

- `harness/`: the parts every variant shares. A loopback fake Pod (OAuth with
  PKCE, two contexts, list, edit) as Vite middleware, the SDK baseline switch,
  the task fields and texts, the reference screen (`screen.tsx`: Focus Zen,
  header menu with a View submenu, routed task dialog with an SDK
  `ResourceEditor`, a calendar-date chooser in the editor fields), its layout
  CSS and the theme and variant contract (`theme.css`).
- `apps/base`, `apps/aria`, `apps/radix`: the same screen on shadcn/ui 4.23.0
  over Base UI, React Aria Components and Radix. Each passes its primitives to
  the screen in `src/kit.tsx`; `src/components/ui` is what `shadcn add`
  generated, with the edits named in the write-up. Radix took part in the
  interop gate only.
- `ui-aria/`: the React Aria kit as a versioned package, for the update-path
  demonstration and the notes app.
- `apps/notes`: the notes app an assistant built from a short owner brief on
  the package; `AUTHORING.md` and `NOTES.md` were its starting point.
- `scripts/`: the evidence. `gate.mjs` (stage 1, `--browser=webkit` for
  WebKit), `interaction.mjs`, `roundtrip.mjs` (calendar-date persistence),
  `contrast.js` with `evidence.mjs` and its controls in
  `contrast-selftest.mjs` (stage 2), `sizes.mjs` and `notes-check.mjs`
  (stage 3), `prompt-copy.mjs` (isolated copies for the prompt runs),
  `sheets.mjs` (contact sheets), `final.sh` (all of it), and three
  `probe-*.mjs` scripts that isolate individual findings.
- `evidence/`: the JSON results, the prompt runs' changes (`change.diff`)
  and the contact sheets the write-up cites. Single screenshots and logs are
  regenerated by `final.sh` and not kept.

## Run

Node 24 and pnpm 11, as in the template. The SDK main baseline needs a
local `sempods-typescript` clone; the default baseline is the published
`@sempods/app-sdk` 0.6.0.

```bash
pnpm install
pnpm exec playwright install chromium webkit
node scripts/vendor-sdk-main.mjs ~/projects/dast/sempods-typescript
sh scripts/final.sh
```

`pnpm --filter spike-aria dev` (or `spike-base`) starts a variant on its own
port; sign in with `http://127.0.0.1:<port>/alice` as the Pod address and
choose the context "work". `SDK=main` before the command uses the SDK main
build. Address parameters `theme`, `actions`, `secondary` and `lang=de`
switch the theme, the component variants and the language.

## Update-path demonstration

1. `pnpm pack` in `ui-aria/` gives 0.1.1; the same package without the
   `shouldCloseOnInteractOutside` line, packed as 0.1.0, is the release
   before the fix.
2. `node scripts/prompt-copy.mjs aria <dir>` copies the app; give it the warm
   `theme.css` from the prompt run, remove `src/kit.tsx`, `src/components`
   and `src/lib`, import the kit from `@sempods-spike/ui-aria`, add
   `@source "../node_modules/@sempods-spike/ui-aria/src";` to `index.css`
   and depend on the 0.1.0 tarball.
3. `node scripts/gate.mjs aria --sdk=main --apps=<dir>/apps` fails
   `close-click-cancel`; after switching the dependency to 0.1.1 and
   `pnpm install`, all checks pass and only `package.json` and the lockfile
   changed.
