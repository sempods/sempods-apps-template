# @sempods/create-apps

Creates a sempods apps repository:

```sh
pnpm create @sempods/apps my-sempods-apps
```

The repository starts from the starter of the `@sempods/apps` version this
package depends on (always the same version) and records that starter as its
baseline in `.sempods-baseline.json`. Open the new folder in your coding
assistant and follow its `README.md`.
